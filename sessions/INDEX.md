# Session index — klin

klin's sessions are its own. Work here is never part of a consuming project's
session: the decision to extract this tooling belongs in the project that made
it, and how the tooling got built is logged here.

| # | Date | Log | What happened |
|---|---|---|---|
| 1 | 2026-08-23 | [session 1](2026-08-23_session_1.md) | Repo birth. The ledger, policy engine, renderer, CLI and plugin, with no vendor adapter by design. 46 tests. Verified against a real consuming project's policy document. |
| 2 | 2026-08-23 | [session 2](2026-08-23_session_2.md) | CI: pytest across 3.11-3.13 and the prose gate. The prose action is a cross-repo reference to the sibling marketplace, which is a coupling worth knowing about. |
| 3 | 2026-08-24 | [session 3](2026-08-24_session_3.md) | Secrets. Windows has no per-application ACL and Credential Manager dies with the profile, so the design is two layers: a KeePassXC database as system of record, the OS vault as a cache klin reads. Ships `klin secret`, a `secrets:` manifest block, and a Windows CI runner. |
| 4 | 2026-08-24 | [session 4](2026-08-24_session_4.md) | The fetch adapters. `klin fetch hf` and `klin fetch civitai`, discovered rather than listed, so vendor three is one new file. The Civitai permission flags are mapped to licence families and the contested row is written down as a judgment. Validating the mapping against the live API corrected two of the eight models it was specified from. |
| 5 | 2026-08-24 | [session 5](2026-08-24_session_5.md) | Reading the licence the vendor published. `license: other` is a statement about the Hub's vocabulary, and the answer sits in the two fields beside it; klin read the tag and stopped, so the two FLUX models were reported unclassifiable while their terms were one link away. A bespoke-lora licence link turns out to carry Civitai's flags as query parameters, so it resolves through the table that already exists. The second follow-up filed against klin was not a defect and is recorded rather than fixed. |
| 6 | 2026-08-26 | [session 6](2026-08-26_session_6.md) | The index: what is on this machine, and what made it. A ComfyUI output is self-describing, so tracing 1,315 of 1,384 images back to their models is a scan rather than archaeology. Models resolve by filesystem identity because all fourteen of the consuming project's recorded models have different filenames in the tree than in the ledger. Then four defects the index exposed: the ship gate passed silently over licences klin could not classify, an adapter's derived empty family list was indistinguishable from a missing one, the Hub's digest was read under a key the API does not use, and recording the licence terms was tied to the classification path. Adoption of a pre-existing tree became the default rather than a flag. One commit reverts another whose reasoning did not survive being checked. |
| 7 | 2026-08-26 | [session 7](2026-08-26_session_7.md) | `klin gen comfy`, whose point is not driving a sampler but knowing the licence posture of a workflow before the GPU starts. A graph names its models, the index resolves them to records, the policy engine judges records: the chain was complete before this verb existed. `--check` refuses to queue when the output could not ship, which inverts the order the consuming project actually lived through, generating 1,384 plates and then finding 66 unusable. Roles are located by the same graph traversal the index uses for reading, and patching six real templates found two defects no synthetic graph reached: a direction-blind walk follows the wrong edge through ControlNetApplyAdvanced, and Flux and Z-Image have no separate negative prompt, so writing one overwrote the positive. Verified end to end against a live ComfyUI. |
| 8 | 2026-08-27 | [session 8](2026-08-27_session_8.md) | `klin conform blender`, the verb the role table had named since session 1. A project whose atlas is a grid of flat swatches does not author a texture per asset, so conforming is pointing every loop of a material at one texel, and pinning to a coordinate rather than a colour is what lets one edit re-grade everything at once. The uv gate re-imports what it exported, because glTF and Blender disagree about where the origin is and a pin that is right in the scene can be inverted in the file. A packaging assertion written for the new script found that an installed klin had not been able to start since session 6: the wheel carried nine modules and no subpackages, and the session-6 revert that re-broke it had been misled by a stale build directory, which is reproduced here. The first real Blender run found three more defects no stub could reach, the worst being an atlas embedded as a one-pixel placeholder rather than referenced. TRELLIS.2 also arrives from the consuming project, carrying the patch that makes its geometry path clean. 363 tests. |
| 9 | 2026-08-27 | [session 9](2026-08-27_session_9.md) | `--map SLOT=SWATCH`, because conform was specified against slots named after swatches and that is only true of a mesh somebody authored for the project. A bought pack names its materials for what they look like, and the same document that specified the naming also listed a CC0 pack as input, so both cases were always in scope and one had no mechanism. Found by the consuming project trying it on a real asset: the refusal was correct, and reading the mesh showed the prop was already atlas-native with 216 uvs across two cells, so conforming it would have flattened it. 372 tests. |
