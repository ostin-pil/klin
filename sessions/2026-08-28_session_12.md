# Session 12: a finder owes nothing downstream

**Date**: 2026-08-28
**Branch**: `feature/session-12-itch` (worktree, `.claude/worktrees/session-12-itch`)

## Why now

The consuming project's last acquisition needed a person only because itch.io
was a browser-shaped hole in the toolchain: the pack itself took one browse
and one page read to choose, and the download — the only genuinely gated step
— took a click. K. asked for the browse and the page read to stop costing
clicks. The role table has held a slot for this shape since session 1:
`fetch` makes bytes appear and owes the ledger a record; `find` only looks
and owes nothing downstream, which is why it is a new verb and not a fetch
flag.

## What the surface turned out to be

A research pass against the live site (2026-08-28) found everything needed
without auth, cookies or a js engine, and each fact became a design
constraint recorded in the adapter's docstring:

- The official server-side API is about the key owner's own account — no
  search, no browse, no arbitrary public page. Their docs point at RSS.
- Browse pages serve RSS by appending `.xml`, with `plainTitle`, `price`,
  `link` and dates per item. No feed carries a licence, tags, or the author
  as a field.
- Filter segments have a canonical order (licence, then free or a sort, then
  tag) and **three segments trip a Cloudflare challenge two do not** —
  URL-pattern-specific, not rate-based. `browse_url` refuses a third segment
  with the reason, because a command line that 403s intermittently is worse
  than one that says no.
- `/search` is disallowed by robots.txt; browse and project pages are not.
  So there is no search flag, deliberately.
- A project page is fully server-rendered, `<url>/data.json` is clean json,
  and "Name your own price" lives only in the page's buy row.
- The `Asset license` row exists only when the creator filled the field in.
  The preview prints it verbatim when present, and when absent says the
  metadata declares nothing and points at the page — a storefront is not a
  licence, and paraphrasing a description into one would be the invention
  the fetch adapters' first rule forbids.

## Shape

`klin/find/` mirrors `klin/fetch/`: adapters discovered by `NAME` +
`configure`, a second catalogue is a new file. `net.get_text` joins
`get_json`, same honest User-Agent. The wheel-check list in CI gains the two
new files, because that list is hardcoded and the subpackage-dropping trap
it guards was real for six sessions once.

## Proven

387 tests (378 + 9), all offline against canned shapes from the live site.
Live: `find itch --free --tag tavern` returns a page of listings with
prices and links; `find itch battleroach/low-poly-m` shows name-your-own-
price from the buy row, tags from data.json, the info table, and the honest
no-licence-row answer. `--licence cc0 --tag tavern` returns an empty page,
which is the catalogue's truth rather than a defect: the licence filter
only catches creators who filled the field in, and the pack that prompted
all of this did not.
